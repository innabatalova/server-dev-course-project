## Структура сайта

Две части: раздел «Лабораторные» (5 работ) и раздел «Курсовой проект». Тема курсового проекта пока не выбрана.

| URL | Страница |
|---|---|
| `/` | Главная, развилка на два раздела |
| `/labs` | Список лабораторных |
| `/labs/1` | Лаба 1, форма обратной связи |
| `/labs/1/headers` | Лаба 1, результат `get_headers` |
| `/labs/2` … `/labs/5` | Заглушки |
| `/course` | Курсовой проект, заглушка |

Навигация: логотип в шапке ведёт на `/`; на вложенных страницах есть ссылка «← к списку лабораторных»; ссылки на разделы продублированы в подвале.

## Принятые решения

- Подвал сделан самостоятельно: три колонки (о проекте, разделы, лабораторные) и нижняя строка с копирайтом.
- Навигация расположена во второй строке шапки и дублируется в подвале.
- Форма лабы 1 отправляется на внешний URL `https://httpbin.org/post`, поэтому директиву `@csrf` в форме не используем: токен не должен уходить на сторонний сервер.
- Запуск `composer run dev`: из стандартного скрипта убраны очереди и `pail` (на Windows нет расширения `pcntl`).
